# EVER FLAME LOGISTICS 官网交付总览与功能清单

## 1. 项目概述

- 项目主体：深圳市恒长明国际货运代理有限公司。
- 英文全称：Shenzhen Ever Flame International Logistics Co., Ltd.
- 展示品牌：EVER FLAME LOGISTICS。
- 网站目标：让中国出口商及海外进口商快速了解公司的空运货代服务、重点目的地、货物能力和联系路径。
- 核心业务：从中国出口至印度、马来西亚及部分南亚、东南亚目的地的国际空运。
- 核心服务：机场到机场、门到门、提货、仓储、出口报关协调、目的地协调及末端派送安排。
- 视觉基准：`design/reference-homepage.png`，即最新一轮效果图的第 3 个方案。

## 5. 原型运行与验证

```bash
npm install
npm run dev
npm run build
npm run test:sites
```

原型没有生产数据依赖。通过 History API 处理本地路由，刷新、返回、前进和语言对应跳转均属于验收范围。

## 6. 上线前仍需提供

- 正式 Logo 及品牌使用规范；若暂不提供，可继续使用文字品牌。
- 已核实的公司地址、电话、邮箱、联系人、微信和 WhatsApp。
- 微信二维码及 WhatsApp 真实链接（如需展示）。
- 营业执照或其他允许公开的资质材料及使用授权。
- 可公开使用的公司、团队、仓库、货物或案例照片。
- 表单接收邮箱、表单服务或后端接口、安全与数据保留方案。
- 域名、隐私主体信息、Cookie/分析工具决定及适用法律文本复核。
- 最终货物接收规则、禁限运品范围及航空公司审核流程。
