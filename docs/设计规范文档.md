# EVER FLAME LOGISTICS 官网设计规范

## 1. 选定视觉方向

- 基准图：`design/reference-homepage.png`。
- 方向：轻盈、国际化、编辑式的 B2B 空运官网。
- 核心视觉：大面积暖白背景、深海军蓝排版、极少量橙色强调、真实无品牌货运摄影、宽松留白、图片与文字交错。
- 实现调整：效果图中混用的衬线标题统一改为系统无衬线字体，以保证英文和简体中文稳定一致；未经确认的口号改为事实性描述。

## 2. 设计原则

1. **业务先于装饰**：首屏先说明从中国出口、空运货代及重点市场。
2. **图片证明场景**：只使用货机、货盘、货站和货车等真实操作场景，不使用城市地标表达网点。
3. **一屏一个重点**：每个区域只承担一个主要信息任务。
4. **克制强调**：橙色只用于 CTA、编号、焦点和少量状态，不作为大面积背景。
5. **避免模板堆叠**：优先使用排版、分组、留白和细分隔线，不把所有内容做成卡片。
6. **双语同构**：中英文组件、顺序和路由一一对应，允许文字自然换行但不删减关键信息。

## 4. 字体与排版

### 4.1 字体栈

```css
ui-sans-serif,
-apple-system,
BlinkMacSystemFont,
"Segoe UI",
"PingFang SC",
"Hiragino Sans GB",
"Microsoft YaHei",
Arial,
sans-serif
```

不依赖在线字体，保证英文及简体中文在常见系统中稳定显示。

### 4.2 字号与行高

| 层级 | 桌面范围 | 移动端范围 | 行高 |
| --- | --- | --- | --- |
| 首页 H1 | 52–91px | 42–64px | 1.04 |
| 内页 H1 | 48–83px | 42–64px | 1.04 |
| H2 | 34–64px | 30–48px | 1.08 |
| H3 | 21px 起 | 20px 起 | 1.25 |
| 正文 | 16–17px | 16px | 1.72 |
| 引导正文 | 17–21px | 17px | 1.72 |
| Eyebrow / 编号 | 12–13px | 12px | 1.3 |

标题字距约 `-0.03em`；机场代码字距约 `0.1em`；大写辅助标题字距约 `0.16em`。

## 5. 栅格、宽度与间距

- 主内容最大宽度：1280px。
- 页头内容最大宽度：1400px。
- 桌面页面左右安全边距：至少 32px，常规 48–64px。
- 内页主要纵向区块：64–112px。
- 组件内部常用间距：8、12、16、24、32、48、64px。
- 首页首屏：约 45/55 文字与图片双栏。
- 内页首屏：约 48/52 文字与图片双栏。
- 服务交错区：50/50。
- 文本最大阅读宽度：约 42rem 或 65 个字符。

## 6. 圆角、边框与阴影

- 按钮圆角：2px，接近直角。
- 输入框：0px 圆角。
- 卡片：默认不使用。
- 分隔：优先 1px `--line`。
- 下拉菜单：1px 边框和低透明阴影 `0 18px 45px rgb(3 31 57 / 10%)`。

## 7. 图片规范

### 7.1 已使用图片

| 文件 | 推荐比例 | 用途 |
| --- | --- | --- |
| `hero-air-cargo-loading.png` | 3:2 | 首页与内页首屏。 |
| `airport-to-airport.png` | 16:10 | 机场到机场服务及印度页。 |
| `door-to-door.png` | 16:10 | 门到门服务。 |
| `cargo-warehouse.png` | 16:9 | 货物能力及仓储场景。 |

### 7.2 构图与色调

- 明亮自然日光或清洁的货站工业光。
- 白色无品牌货机、银灰货盘、暖灰地面、少量安全黄作为环境色。
- 主体必须有现实比例、正确装载关系和完整可辨轮廓。
- 使用 `object-fit: cover`；桌面保留主要机械和货盘，移动端优先保留货物与装载动作。

### 7.3 禁止事项

- 航空公司、机场、车辆或设备品牌标志。
- 城市地标、国旗或不准确地图来暗示直营网点。
- 可读货签、车牌、二维码、危险品标签或真实个人信息。
- 过度电影感、灾难氛围、军用飞机、危险操作、扭曲机械和重复人物。
- 将整张效果图裁切成网站图片使用。

## 8. 组件规范

### 8.1 页头

- 高度：桌面 78px，移动端 70px。
- 白色背景、轻底边线、吸顶。
- 文字品牌左对齐；桌面导航右对齐。
- 下拉菜单通过点击展开，不依赖悬停。

### 8.2 按钮

- 最小高度：52px。
- 主按钮：橙底白字；悬停使用深橙。
- 次按钮：深蓝描边；悬停转深蓝底白字。
- 焦点：3px 橙色轮廓，外偏移 4px。
- 禁用提交按钮：保留文字可读，透明度约 72%。

### 8.3 机场代码栏

- 桌面 8 列，平板 4 列，手机 2 列。
- 只用分隔线，不加地图、旗帜、徽章或机场图标。
- 目的地页可在代码下显示城市名。

### 8.4 服务切换

- 两个等宽文字标签，选中项显示橙色 4px 下边线。
- 面板为浅蓝灰底，文字与图片双栏；移动端单列。
- 保留 ARIA 标签页语义和键盘方向键操作。

### 8.5 货物折叠项

- 标题行包含编号、标题、摘要和文字状态。
- 不使用手绘加减图标。
- 展开内容包含说明和审核清单。

### 8.6 表单

- 桌面两列；长文本占整行；移动端单列。
- 输入高度至少 52px，边框 `--line-dark`。
- 错误边框为深红 2px，并显示关联错误文本。
- 成功状态替换表单主体，避免误以为重复发送。

### 8.7 页脚

- 白底、顶部细分隔线。
- 品牌与说明在左，核心链接在右；移动端纵向排列。
- 隐私政策只从页脚进入。

## 9. 中英文适配

- 英文为默认站点，中文路由增加 `/zh`。
- 语言切换保持当前页面，不自动检测浏览器语言。
- 中文标题不强制逐词断行，允许组件高度自然增加。
- 品牌固定使用 `EVER FLAME LOGISTICS`；法律文本分别使用完整中英文公司名。
- 英文优先提及 WhatsApp，中文优先提及微信，但无真实资料时隐藏外部联系按钮。
- 机场代码保持拉丁字母，城市名称按语言显示。

## 10. 动效规范

- 链接、按钮、导航反馈：180ms，标准 ease。
- 内容首次显现：520ms，向上 18px + 透明度变化，只触发一次。
- 不使用循环动画、复杂航线动画、视差或大面积移动背景。
- 减少动画模式下关闭平滑滚动及可感知动画，内容直接显示。

## 11. 响应式断点

| 断点 | 行为 |
| --- | --- |
| `>1080px` | 完整桌面布局。 |
| `901–1080px` | 压缩导航间距和首屏内边距。 |
| `681–900px` | 切换移动菜单；主要双栏转单栏；机场 4 列。 |
| `≤680px` | 手机排版；机场 2 列；流程 2×2；表单单列。 |

验收视口为 390×844、768×1024 和 1440×900。

## 12. 无障碍规范

- 正文与背景以 WCAG AA 对比度为目标。
- 所有交互最小高度约 44px。
- 页面只有一个 H1，标题层级连续。
- 页头提供跳到主要内容链接。
- 所有图片有语言对应替代文本；装饰元素不承载关键信息。
- 焦点不可被吸顶页头或浮层遮挡。
- 错误不能只依赖红色表达，必须提供文本。
