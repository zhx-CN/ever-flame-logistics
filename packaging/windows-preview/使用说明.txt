EVER FLAME LOGISTICS 网站本地预览包
====================================

使用方法
--------
1. 请先将 ZIP 压缩包完整解压到一个普通文件夹。
2. 双击“启动网站.bat”。
3. 服务启动后，默认浏览器会自动打开网站。
4. 浏览完成后，关闭黑色服务窗口或在窗口中按 Ctrl+C。

说明
----
- 本预览包只在当前电脑本地运行，不会上传或保存任何表单数据。
- 不需要安装 Node.js、Python、数据库或其他开发工具。
- Windows 首次运行脚本时可能显示安全提醒，请确认文件来自可信的项目提供方。
- 不要直接在 ZIP 压缩包内部运行，请先完整解压。
- 若默认端口 4173 已被占用，程序会自动尝试后续端口。

目录
----
- 启动网站.bat：双击启动。
- www：已经构建完成的网页文件。
- server：本地静态服务器脚本。

本包仅用于网站效果演示，不包含线上部署、真实表单提交或后台服务。
