# EVER FLAME LOGISTICS 交付包

## 直接预览

将 `EVER-FLAME-LOGISTICS-preview-windows.zip` 发给接收方。接收方完整解压后，双击 `启动网站.bat` 即可查看网页，无需安装 Node.js 或 Python。

交付目录中同时保留了同名解压文件夹，方便本机直接验证。

## 源码

`EVER-FLAME-LOGISTICS-source.zip` 包含 React/Vite 源码、生成图片、设计基准、文档、测试及打包脚本，不包含 `node_modules`、npm 缓存、日志或旧构建目录。

源码开发命令：

```powershell
npm.cmd install
npm.cmd run dev
```

## 完整性

`SHA256SUMS.txt` 提供两个 ZIP 文件的 SHA-256 校验值。

## 演示边界

本项目是双语展示原型。联系表单仅演示校验与成功状态，不发送、不保存数据；不包含下单、报价、追踪、账号、数据库或后台服务。
